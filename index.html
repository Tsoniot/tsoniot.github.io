Xác Nhận Đơn Hàng IoT

Hướng Dẫn Nạp Web Serial Qua Trình Duyệt

Bước 1: Sử dụng trình duyệt hỗ trợ

Web Serial API yêu cầu các trình duyệt nền tảng Chromium như Google Chrome, Microsoft Edge, Brave, Opera trên máy tính PC/Laptop.

Bước 2: Chuẩn bị Cáp USB Type-C & Driver

Đảm bảo dây cáp Type-C của bạn có truyền dữ liệu (Data cable) chứ không chỉ sạc. Nếu máy tính chưa nhận cổng COM, hãy tải Driver chíp nạp tương ứng:

  • CH340 Driver: Phổ biến trên các mạch ESP32/ESP8266 giá rẻ.
  • CP2102 / CP2104 Driver: Thường dùng cho bo mạch ESP32 DevKit cao cấp.

Bước 3: Thao tác vào chế độ Bootloader (Nếu bị lỗi kết nối)

Khi bấm "Nạp Firmware", nếu màn hình báo timeout: Hãy nhấn giữ nút BOOT trên mạch ESP32 -> Bấm thả nút EN/RST -> Thả nút BOOT ra để mạch vào chế độ tải Code.
